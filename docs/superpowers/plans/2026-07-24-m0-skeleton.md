# WP Safe Mode M0 — Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the v2 skeleton — dev toolchain, autoloader, environment probe, a dual-backend storage layer proven by one shared conformance suite, a minimal router, and a Preact shell that builds into `src/public` — so that every later milestone has a tested foundation to build on.

**Architecture:** v2 lives in new PascalCase top-level directories (`src/`, `frontend/`, `docker/`, `tests/`) alongside the untouched v1.1 codebase already at the repository root. All PHP executes inside a `php:8.0-cli` container because the host has no PHP and no Composer; this also pins every test to the real version floor. Storage is defined by narrow interfaces with two implementations (SQLite via PDO, JSON files) that are held to a single abstract conformance test, so the fallback is proven equivalent rather than assumed.

**Tech Stack:** PHP 8.0 (zero runtime dependencies), PDO/SQLite, PHPUnit 9.6 (dev-only, via Composer inside the container), Docker Compose, Vite 6, Preact 10, Tailwind CSS 4.

**Spec:** `docs/superpowers/specs/2026-07-24-wp-safe-mode-design.md`. Section references below (§n) point there.

**Branch:** create `feat/m0-skeleton` from `main` before Task 1. `main` currently holds v1.1 plus the merged spec.

## Global Constraints

- **PHP 8.0.0 is the floor.** Every file starts `<?php` then `declare(strict_types=1);`.
- **No `enum`.** Enums are PHP 8.1. Use `final class X { public const A = 'a'; }`. *(This corrects §8 of the spec, which shows `Tier` as an enum — see Task 3, Step 1.)*
- **No `readonly` properties** (8.1), **no `never` return type** (8.1), **no `array_is_list()`** (8.1), **no `new` in initializers** (8.1), **no fibers** (8.1).
- **Available and encouraged on 8.0:** constructor property promotion, union types, `match`, nullsafe `?->`, named arguments, `str_contains`/`str_starts_with`/`str_ends_with`, trailing commas in parameter lists.
- **Zero runtime dependencies.** Nothing under `src/` may `require` anything from `vendor/`. Composer is dev-only; the shipped ZIP contains no vendor directory.
- **Directory names under `src/` are PascalCase and must match the namespace segment exactly.** Production hosts are Linux (case-sensitive); the dev Mac is not. A case mismatch works locally and 500s in production. The two exceptions are `src/public/` (web assets, not a namespace) and `src/index.php`.
- **Root namespace is `WPSafeMode\`,** mapping to `src/`. `WPSafeMode\Storage\Sqlite\SqliteConfigStore` lives at `src/Storage/Sqlite/SqliteConfigStore.php`.
- **All PHP runs in Docker.** Every command in this plan is prefixed `docker compose run --rm dev`. Never instruct the engineer to run `php` or `composer` on the host — neither exists there.
- **Never modify v1.1 files.** `controller/`, `model/`, `view/`, `core/`, `services/`, `helpers/`, `security/`, `ext/`, `assets/`, `sfstore/`, `autoload.php`, `index.php` at the repository root belong to v1.1 and are out of scope for every task in this plan. Note that root `index.php` and root `autoload.php` already exist and are v1.1's — ours are `src/index.php` and `src/autoload.php`.
- **`data/` is never committed.** It is already in `.gitignore` (§5.4, §15.1).

```php
declare(strict_types=1);

namespace WPSafeMode\Core;

final class EnvironmentReport
{
    public function __construct(
        public string $phpVersion,
        public bool $phpSatisfied,
        public bool $hasPdoSqlite,
        public bool $hasMysqli,
        public bool $hasOpenssl,
        public bool $hasSodium,
        public bool $hasExec,
        public int $freeDiskBytes,
        public ?string $wpRoot,

    }

    /**

     *

    public function toArray(): array
    {
        return [
            'php_version'     => $this->phpVersion,
            'php_satisfied'   => $this->phpSatisfied,
            'has_pdo_sqlite'  => $this->hasPdoSqlite,
            'has_mysqli'      => $this->hasMysqli,
            'has_openssl'     => $this->hasOpenssl,
            'has_sodium'      => $this->hasSodium,
            'has_exec'        => $this->hasExec,
            'free_disk_bytes' => $this->freeDiskBytes,
            'wp_detected'     => $this->wpRoot !== null,

    }
}
```

- [ ] **Step 4: Write the probe**

Create `src/Core/Environment.php`:

```php
<?php

declare(strict_types=1);

namespace WPSafeMode\Core;

final class Environment
{
    /** Directories to search for WordPress, relative to the install directory. */
    private const WP_CANDIDATES = ['..', '.', '../..', '../wordpress'];

    public static function probe(?string $baseDir = null): EnvironmentReport
    {
        $baseDir = $baseDir ?? dirname(__DIR__);
        $free = @disk_free_space($baseDir);

        return new EnvironmentReport(
            phpVersion:    PHP_VERSION,
            phpSatisfied:  version_compare(PHP_VERSION, Version::MIN_PHP, '>='),
            hasPdoSqlite:  extension_loaded('pdo_sqlite'),
            hasMysqli:     extension_loaded('mysqli'),
            hasOpenssl:    extension_loaded('openssl'),
            hasSodium:     extension_loaded('sodium'),
            hasExec:       self::execUsable(),
            freeDiskBytes: is_float($free) ? (int) $free : 0,
            wpRoot:        self::findWordPressRoot($baseDir),
        );
    }

    /**
     * exec() can exist but be listed in disable_functions, which is the
     * common shared-hosting configuration. Both must be checked.
     */
    private static function execUsable(): bool
    {
        if (!function_exists('exec')) {
            return false;
        }

        $disabled = array_map(
            'trim',
            explode(',', (string) ini_get('disable_functions'))
        );

        return !in_array('exec', $disabled, true);
    }

    /**
     * A directory is the WordPress root when it holds both wp-config.php and
     * wp-includes/version.php. Requiring both avoids matching a stray
     * wp-config.php backup.
     */
    private static function findWordPressRoot(string $baseDir): ?string
    {
        foreach (self::WP_CANDIDATES as $candidate) {
            $path = realpath($baseDir . '/' . $candidate);

            if ($path === false) {
                continue;
            }

            if (is_file($path . '/wp-config.php') && is_file($path . '/wp-includes/version.php')) {
                return $path;
            }
        }

        return null;
    }
}
```

- [ ] **Step 2: Write the failing conformance suite**

Create `tests/Storage/StorageConformanceTest.php`:

```php
<?php

declare(strict_types=1);

namespace WPSafeMode\Tests\Storage;

use PHPUnit\Framework\TestCase;
use WPSafeMode\Storage\Contracts\ConfigStore;

/**
 * One suite, two backends. Every assertion here must hold identically for
 * SQLite and for the JSON fallback — that equivalence is the entire point
 * of the fallback (spec 7).
 */
abstract class StorageConformanceTest extends TestCase
{
    protected string $dataDir;

    abstract protected function makeConfigStore(string $dataDir): ConfigStore;

    protected function setUp(): void
    {
        $this->dataDir = sys_get_temp_dir() . '/wpsm-store-' . bin2hex(random_bytes(6));
        mkdir($this->dataDir, 0700, true);
    }

    protected function tearDown(): void
    {
        $this->removeRecursively($this->dataDir);
    }

    private function removeRecursively(string $path): void
    {
        if (!is_dir($path)) {
            return;
        }

        foreach (scandir($path) ?: [] as $entry) {
            if ($entry === '.' || $entry === '..') {
                continue;
            }
            $full = $path . '/' . $entry;
            is_dir($full) ? $this->removeRecursively($full) : unlink($full);
        }

        rmdir($path);
    }

    public function testGetReturnsDefaultWhenKeyIsAbsent(): void
    {
        self::assertNull($this->makeConfigStore($this->dataDir)->get('nope'));
        self::assertSame('fb', $this->makeConfigStore($this->dataDir)->get('nope', 'fb'));
    }

    public function testSetThenGetRoundTrips(): void
    {
        $store = $this->makeConfigStore($this->dataDir);
        $store->set('model', 'claude-opus-4-8');

        self::assertSame('claude-opus-4-8', $store->get('model'));
    }

    public function testSetOverwritesExistingKey(): void
    {
        $store = $this->makeConfigStore($this->dataDir);
        $store->set('effort', 'high');
        $store->set('effort', 'xhigh');

        self::assertSame('xhigh', $store->get('effort'));
        self::assertCount(1, $store->all());
    }

    public function testValuesPersistAcrossInstances(): void
    {
        $this->makeConfigStore($this->dataDir)->set('model', 'claude-sonnet-5');

        self::assertSame('claude-sonnet-5', $this->makeConfigStore($this->dataDir)->get('model'));
```

```php
<?php

declare(strict_types=1);

namespace WPSafeMode\Storage\Sqlite;

use PDO;
use PDOException;
use WPSafeMode\Storage\Contracts\StorageException;

final class SqliteConnection
{
    private ?PDO $pdo = null;

    public function __construct(private string $path)
    {
    }

    public function pdo(): PDO
    {
        if ($this->pdo !== null) {
            return $this->pdo;
        }

        $dir = dirname($this->path);

        if (!is_dir($dir) && !@mkdir($dir, 0700, true) && !is_dir($dir)) {
            throw new StorageException('Cannot create data directory: ' . $dir);
        }

        try {
            $pdo = new PDO('sqlite:' . $this->path, null, null, [
                PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES   => false,
            ]);
        } catch (PDOException $e) {
            throw new StorageException('Cannot open SQLite database: ' . $e->getMessage(), 0, $e);
        }

        // Deliberately NOT enabling WAL. WAL needs shared memory, which fails
        // on the NFS-backed filesystems some shared hosts use. The default
        // rollback journal works everywhere; busy_timeout covers contention.
        $pdo->exec('PRAGMA busy_timeout = 5000');
        $pdo->exec('PRAGMA foreign_keys = ON');

        SqliteSchema::install($pdo);

        return $this->pdo = $pdo;
    }
}
```

```php
<?php

declare(strict_types=1);

namespace WPSafeMode\Storage\Json;

use JsonException;
use WPSafeMode\Storage\Contracts\StorageException;

/**
 * Read-modify-write for a small mutable JSON file.
 *
 * Writes go to a temporary file and are moved into place with rename(), which
 * is atomic within a filesystem. A crashed request therefore leaves either the
 * previous complete file or the new complete file, never a truncated one.
 */
final class JsonFile
{
    public function __construct(private string $path)
    {
    }

    public function path(): string
    {
        return $this->path;
    }

    /** @return array<string, mixed> */
    public function read(): array
    {
        if (!is_file($this->path)) {
            return [];
        }

        $raw = file_get_contents($this->path);

        if ($raw === false || $raw === '') {
            return [];
        }

        try {
            $decoded = json_decode($raw, true, 512, JSON_THROW_ON_ERROR);
        } catch (JsonException $e) {
            throw new StorageException('Corrupt JSON store: ' . $this->path, 0, $e);
        }

        return is_array($decoded) ? $decoded : [];
    }

    /** @param array<string, mixed> $data */
    public function write(array $data): void
    {
        $dir = dirname($this->path);

        if (!is_dir($dir) && !@mkdir($dir, 0700, true) && !is_dir($dir)) {
            throw new StorageException('Cannot create data directory: ' . $dir);
        }

        try {
            $json = json_encode(
                $data,
                JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR
            );
        } catch (JsonException $e) {
            throw new StorageException('Cannot encode store: ' . $this->path, 0, $e);
        }

        $tmp = $this->path . '.tmp.' . bin2hex(random_bytes(4));

        if (file_put_contents($tmp, $json, LOCK_EX) === false) {
            throw new StorageException('Cannot write store: ' . $tmp);
        }

        @chmod($tmp, 0600);

        if (!rename($tmp, $this->path)) {
            @unlink($tmp);
            throw new StorageException('Cannot commit store: ' . $this->path);
        }
    }
}
```

```php
<?php

declare(strict_types=1);

namespace WPSafeMode\Storage\Json;

use WPSafeMode\Storage\Contracts\ConfigStore;

final class JsonConfigStore implements ConfigStore
{
    private JsonFile $file;

    public function __construct(string $path)
    {
        $this->file = new JsonFile($path);
    }

    public function get(string $key, ?string $default = null): ?string
    {
        $data = $this->file->read();

        // array_key_exists, not isset() — isset() reports false for a stored
        // empty string and would conflate it with an absent key.
        return array_key_exists($key, $data) ? (string) $data[$key] : $default;
    }

    public function set(string $key, string $value): void
    {
        $data = $this->file->read();
        $data[$key] = $value;
        $this->file->write($data);
    }

    public function has(string $key): bool
    {
        return array_key_exists($key, $this->file->read());
    }

    public function delete(string $key): void
    {
        $data = $this->file->read();

        if (!array_key_exists($key, $data)) {
            return;
        }

        unset($data[$key]);
        $this->file->write($data);
    }

    public function all(): array
    {
        $data = $this->file->read();
        ksort($data);

        $out = [];
        foreach ($data as $key => $value) {
            $out[(string) $key] = (string) $value;
        }

        return $out;
    }
}
```

```php
<?php

declare(strict_types=1);

namespace WPSafeMode\Storage\Sqlite;

use PDOException;
use WPSafeMode\Storage\Contracts\SessionRepo;
use WPSafeMode\Storage\Contracts\StorageException;
use WPSafeMode\Storage\Session;

final class SqliteSessionRepo implements SessionRepo
{
    private const COLUMNS = [
        'id', 'title', 'blade', 'status', 'model', 'effort',
        'created_at', 'updated_at', 'lock_token', 'lock_expires_at',
        'retry_count', 'retry_after_at', 'in_tokens', 'out_tokens',
        'cache_read_tokens', 'cache_write_tokens', 'cost_micros',
    ];

    public function __construct(private SqliteConnection $connection)
    {
    }

    public function create(Session $session): void
    {
        $placeholders = array_map(static fn (string $c): string => ':' . $c, self::COLUMNS);

        $sql = 'INSERT INTO sessions (' . implode(', ', self::COLUMNS) . ')'
             . ' VALUES (' . implode(', ', $placeholders) . ')';

        try {
            $this->connection->pdo()->prepare($sql)->execute($this->bindings($session));
        } catch (PDOException $e) {
            throw new StorageException('Session already exists: ' . $session->id, 0, $e);
        }
    }

    public function find(string $id): ?Session
    {
        $stmt = $this->connection->pdo()->prepare('SELECT * FROM sessions WHERE id = :id');
        $stmt->execute([':id' => $id]);
        $row = $stmt->fetch();

        return $row === false ? null : Session::fromRow($row);
    }

    public function update(Session $session): void
    {
        $assignments = [];
        foreach (self::COLUMNS as $column) {
            if ($column !== 'id') {
                $assignments[] = $column . ' = :' . $column;
            }
        }

        $sql = 'UPDATE sessions SET ' . implode(', ', $assignments) . ' WHERE id = :id';

        $stmt = $this->connection->pdo()->prepare($sql);
        $stmt->execute($this->bindings($session));

        if ($stmt->rowCount() === 0 && $this->find($session->id) === null) {
            throw new StorageException('Unknown session: ' . $session->id);
        }
    }

    public function list(int $limit = 50): array
    {
        $stmt = $this->connection->pdo()->prepare(
            'SELECT * FROM sessions ORDER BY created_at DESC, id DESC LIMIT :limit'
        );
        $stmt->bindValue(':limit', $limit, \PDO::PARAM_INT);
        $stmt->execute();

        return array_map(
            static fn (array $row): Session => Session::fromRow($row),
            $stmt->fetchAll()
        );
    }

    public function delete(string $id): void
    {
        $stmt = $this->connection->pdo()->prepare('DELETE FROM sessions WHERE id = :id');
        $stmt->execute([':id' => $id]);
    }

    /** @return array<string, int|string|null> */
    private function bindings(Session $session): array
    {
        $bindings = [];
        foreach ($session->toRow() as $column => $value) {
            $bindings[':' . $column] = $value;
        }

        return $bindings;
    }
```

```php
<?php

declare(strict_types=1);

namespace WPSafeMode\Storage\Json;

use WPSafeMode\Storage\Contracts\SessionRepo;
use WPSafeMode\Storage\Contracts\StorageException;
use WPSafeMode\Storage\Session;

/**
 * One directory per session (spec 7.2). The session record itself lives in
 * session.json; Task 5 adds messages.jsonl beside it.
 */
final class JsonSessionRepo implements SessionRepo
{
    public function __construct(private string $baseDir)
    {
    }

    public function create(Session $session): void
    {
        if ($this->find($session->id) !== null) {
            throw new StorageException('Session already exists: ' . $session->id);
        }

        $this->fileFor($session->id)->write($session->toRow());
    }

    public function find(string $id): ?Session
    {
        $path = $this->pathFor($id);

        if (!is_file($path)) {
            return null;
        }

        $row = (new JsonFile($path))->read();

        return $row === [] ? null : Session::fromRow($row);
    }

    public function update(Session $session): void
    {
        if ($this->find($session->id) === null) {
            throw new StorageException('Unknown session: ' . $session->id);
        }

        $this->fileFor($session->id)->write($session->toRow());
    }

    public function list(int $limit = 50): array
    {
        if (!is_dir($this->baseDir)) {
            return [];
        }

        $sessions = [];

        foreach (scandir($this->baseDir) ?: [] as $entry) {
            if ($entry === '.' || $entry === '..') {
                continue;
            }

            $session = $this->find($entry);

            if ($session !== null) {
                $sessions[] = $session;
            }
        }

        usort(
            $sessions,
            static fn (Session $a, Session $b): int
                => [$b->createdAt, $b->id] <=> [$a->createdAt, $a->id]
        );

        return array_slice($sessions, 0, $limit);
    }

    public function delete(string $id): void
    {
        $path = $this->pathFor($id);

        if (is_file($path)) {
            unlink($path);
        }

        $dir = dirname($path);

        if (is_dir($dir) && (scandir($dir) ?: []) === ['.', '..']) {
            rmdir($dir);
        }
    }

    private function fileFor(string $id): JsonFile
    {
        return new JsonFile($this->pathFor($id));
    }

    /**
     * Session ids are generated by us, never supplied by a user or the model,
     * but this method is the boundary where an id becomes a filesystem path,
     * so it validates rather than trusts (spec 5.6).
     */
    private function pathFor(string $id): string
    {
        if (preg_match('/^[A-Za-z0-9_-]{1,64}$/', $id) !== 1) {
            throw new StorageException('Illegal session id: ' . $id);
        }

        return $this->baseDir . '/' . $id . '/session.json';
    }
}
```

```php
<?php

declare(strict_types=1);

namespace WPSafeMode\Storage\Sqlite;

use Generator;
use WPSafeMode\Storage\Contracts\MessageLog;
use WPSafeMode\Storage\Contracts\StorageException;
use WPSafeMode\Storage\Message;

final class SqliteMessageLog implements MessageLog
{
    public function __construct(private SqliteConnection $connection)
    {
    }

    public function append(string $sessionId, string $role, array $content, ?string $apiMessageId = null): int
    {
        $pdo = $this->connection->pdo();
        $pdo->beginTransaction();

        try {
            $stmt = $pdo->prepare('SELECT COALESCE(MAX(seq), 0) + 1 AS next FROM messages WHERE session_id = :s');
            $stmt->execute([':s' => $sessionId]);
            $seq = (int) $stmt->fetch()['next'];

            $insert = $pdo->prepare(
                'INSERT INTO messages (session_id, seq, role, content_json, api_message_id, created_at)
                 VALUES (:s, :seq, :role, :content, :api_id, :created)'
            );
            $insert->execute([
                ':s'       => $sessionId,
                ':seq'     => $seq,
                ':role'    => $role,
                ':content' => json_encode($content, JSON_THROW_ON_ERROR | JSON_UNESCAPED_UNICODE),
                ':api_id'  => $apiMessageId,
                ':created' => time(),
            ]);

            $pdo->commit();

            return $seq;
        } catch (\Throwable $e) {
            $pdo->rollBack();
            throw new StorageException('Cannot append message: ' . $e->getMessage(), 0, $e);
        }
    }

    public function all(string $sessionId): Generator
    {
        $stmt = $this->connection->pdo()->prepare(
            'SELECT * FROM messages WHERE session_id = :s ORDER BY seq ASC'
        );
        $stmt->execute([':s' => $sessionId]);

        while (($row = $stmt->fetch()) !== false) {
            yield new Message(
                sessionId:    (string) $row['session_id'],
                seq:          (int) $row['seq'],
                role:         (string) $row['role'],
                content:      json_decode((string) $row['content_json'], true, 512, JSON_THROW_ON_ERROR),
                apiMessageId: $row['api_message_id'] === null ? null : (string) $row['api_message_id'],
                createdAt:    (int) $row['created_at'],
            );
        }
    }

    public function count(string $sessionId): int
    {
        $stmt = $this->connection->pdo()->prepare('SELECT COUNT(*) AS n FROM messages WHERE session_id = :s');
        $stmt->execute([':s' => $sessionId]);

        return (int) $stmt->fetch()['n'];
```

Create `src/Storage/Json/JsonMessageLog.php`:

```php
<?php

declare(strict_types=1);

namespace WPSafeMode\Storage\Json;

use Generator;
use WPSafeMode\Storage\Contracts\MessageLog;
use WPSafeMode\Storage\Contracts\StorageException;
use WPSafeMode\Storage\Message;

/**
 * Append-only JSONL, one message per line.
 *
 * Appending is O(1) and a crashed request truncates at most the final line.
 * Reads stream line by line and never load the whole file: a long session's
 * messages.jsonl is the largest object in the data directory (spec 7.2).
 */
final class JsonMessageLog implements MessageLog
{
    public function __construct(private string $baseDir)
    {
    }

    public function append(string $sessionId, string $role, array $content, ?string $apiMessageId = null): int
    {
        $path = $this->pathFor($sessionId);
        $dir = dirname($path);

        if (!is_dir($dir) && !@mkdir($dir, 0700, true) && !is_dir($dir)) {
            throw new StorageException('Cannot create session directory: ' . $dir);
        }

        $seq = $this->count($sessionId) + 1;

        $line = json_encode([
            'session_id'     => $sessionId,
            'seq'            => $seq,
            'role'           => $role,
            'content'        => $content,
            'api_message_id' => $apiMessageId,
            'created_at'     => time(),
        ], JSON_THROW_ON_ERROR | JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES);

        $handle = fopen($path, 'ab');

        if ($handle === false) {
            throw new StorageException('Cannot open message log: ' . $path);
        }

        try {
            if (!flock($handle, LOCK_EX)) {
                throw new StorageException('Cannot lock message log: ' . $path);
            }

            fwrite($handle, $line . "\n");
            fflush($handle);
            flock($handle, LOCK_UN);
        } finally {
            fclose($handle);
        }

        return $seq;
    }

    public function all(string $sessionId): Generator
    {
        $path = $this->pathFor($sessionId);

        if (!is_file($path)) {
            return;
        }

        $handle = fopen($path, 'rb');

        if ($handle === false) {
            throw new StorageException('Cannot read message log: ' . $path);
        }

        try {
            while (($line = fgets($handle)) !== false) {
                $line = trim($line);

                if ($line === '') {
                    continue;
                }

                $row = json_decode($line, true, 512, JSON_THROW_ON_ERROR);

                yield new Message(
                    sessionId:    (string) $row['session_id'],
                    seq:          (int) $row['seq'],
                    role:         (string) $row['role'],
                    content:      $row['content'],
                    apiMessageId: $row['api_message_id'] === null ? null : (string) $row['api_message_id'],
                    createdAt:    (int) $row['created_at'],
                );
            }
        } finally {
            fclose($handle);
        }
    }

    public function count(string $sessionId): int
    {
        $path = $this->pathFor($sessionId);

        if (!is_file($path)) {
            return 0;
        }

        $handle = fopen($path, 'rb');

        if ($handle === false) {
            return 0;
        }

        $count = 0;

        try {
            while (($line = fgets($handle)) !== false) {
                if (trim($line) !== '') {
                    $count++;
                }
            }
        } finally {
            fclose($handle);
        }

        return $count;
    }

    private function pathFor(string $sessionId): string
    {
        if (preg_match('/^[A-Za-z0-9_-]{1,64}$/', $sessionId) !== 1) {
            throw new StorageException('Illegal session id: ' . $sessionId);
        }

        return $this->baseDir . '/' . $sessionId . '/messages.jsonl';
    }
}
```

```php
<?php

declare(strict_types=1);

namespace WPSafeMode\Storage;

use WPSafeMode\Core\EnvironmentReport;
use WPSafeMode\Storage\Contracts\Storage;
use WPSafeMode\Storage\Contracts\StorageException;

final class StorageFactory
{
    public const BACKEND_SQLITE = 'sqlite';
    public const BACKEND_JSON   = 'json';

    /**
     * The backend is decided once, at install, and recorded. There is no
     * runtime switching and no migration between backends in v1 (spec 7).
     *
     * @param string|null $recorded the backend recorded at install, if any
     */
    public static function chooseBackend(bool $hasPdoSqlite, ?string $recorded): string
    {
        if ($recorded === self::BACKEND_JSON) {
            return self::BACKEND_JSON;
        }

        if ($recorded === self::BACKEND_SQLITE) {
            if (!$hasPdoSqlite) {
                throw new StorageException(
                    'This install uses SQLite storage but pdo_sqlite is no longer available on this server.'
                );
            }

            return self::BACKEND_SQLITE;
        }

        return $hasPdoSqlite ? self::BACKEND_SQLITE : self::BACKEND_JSON;
    }

    public static function create(string $dataDir, string $backend): Storage
    {
        return match ($backend) {
            self::BACKEND_SQLITE => new SqliteStorage($dataDir),
            self::BACKEND_JSON   => new JsonStorage($dataDir),
            default              => throw new StorageException('Unknown storage backend: ' . $backend),
        };
    }

    /**
     * Opens storage for a live install, recording the chosen backend the
     * first time so later requests stay on it.
     */
    public static function open(string $dataDir, EnvironmentReport $env): Storage
    {
        $marker = $dataDir . '/backend';
        $recorded = is_file($marker) ? trim((string) file_get_contents($marker)) : null;

        $backend = self::chooseBackend($env->hasPdoSqlite, $recorded === '' ? null : $recorded);

        if ($recorded === null || $recorded === '') {
            if (!is_dir($dataDir) && !@mkdir($dataDir, 0700, true) && !is_dir($dataDir)) {
                throw new StorageException('Cannot create data directory: ' . $dataDir);
            }

            file_put_contents($marker, $backend, LOCK_EX);
            @chmod($marker, 0600);
        }

        return self::create($dataDir, $backend);
    }
}
```

Create `src/Core/Request.php`:

```php
<?php

declare(strict_types=1);

namespace WPSafeMode\Core;

final class Request
{
    public function __construct(
        public string $method,
        public string $uri,
        public string $scriptName = '/index.php',
        public string $rawBody = '',
    ) {
    }

    public static function fromGlobals(): self
    {
        return new self(
            method:     strtoupper((string) ($_SERVER['REQUEST_METHOD'] ?? 'GET')),
            uri:        (string) ($_SERVER['REQUEST_URI'] ?? '/'),
            scriptName: (string) ($_SERVER['SCRIPT_NAME'] ?? '/index.php'),
            rawBody:    (string) file_get_contents('php://input'),
        );
    }

    /**
     * Path with the query string and the install-directory prefix removed,
     * always with a leading slash.
     */
    public function path(): string
    {
        $path = (string) parse_url($this->uri, PHP_URL_PATH);
        $prefix = rtrim(str_replace('\\', '/', dirname($this->scriptName)), '/');

        if ($prefix !== '' && $prefix !== '.' && strpos($path, $prefix) === 0) {
            $path = substr($path, strlen($prefix));
        }

        return '/' . ltrim($path, '/');
    }

    /** @return array<string, mixed> */
    public function json(): array
    {
        if ($this->rawBody === '') {
            return [];
        }

        $decoded = json_decode($this->rawBody, true);

        return is_array($decoded) ? $decoded : [];
    }
}
```

Create `src/Core/Router.php`:

```php
<?php

declare(strict_types=1);

namespace WPSafeMode\Core;

final class Router
{
    /** @var array<string, array<string, callable(Request): Response>> path => method => handler */
    private array $routes = [];

    /** @param callable(Request): Response $handler */
    public function add(string $method, string $path, callable $handler): void
    {
        $this->routes[$path][strtoupper($method)] = $handler;
    }

    public function dispatch(Request $request): Response
    {
        $path = $request->path();

        if (!isset($this->routes[$path])) {
            return Response::notFound();
        }

        $handler = $this->routes[$path][$request->method] ?? null;

        if ($handler === null) {
            return Response::methodNotAllowed();
        }

        return $handler($request);
    }
}
```
